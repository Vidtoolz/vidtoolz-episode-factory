# Orbit to travel handoff calibration

Experiment-only DIRN17 candidates. Production generation is unchanged.

- Baseline: direct 73-degree orbit-to-travel redirect.
- Tangent departure: one 60-frame direction/speed envelope; reject if its exit creates a new seam.
- Settle then launch: 15-frame rest between a decelerated orbit and the existing travel launch.

## Real technical filter

All three projects imported successfully and were read back from frame B−60
through B+120.

- Baseline reproduced the 73.119° one-frame redirect.
- Tangent departure reduced the redirect to 4.961°, but Earth Studio coupled
  the dense position samples into a severe altitude-speed spike; it is rejected
  before human review.
- Settle then launch reduced meaningful one-frame turning to 0.014°, reduced
  pan acceleration from 360.000 to 51.429°/s², and preserved a clean launch
  after a 15-frame rest. It is the sole technical finalist.

Production remains unchanged until Mikko records a visual verdict.
