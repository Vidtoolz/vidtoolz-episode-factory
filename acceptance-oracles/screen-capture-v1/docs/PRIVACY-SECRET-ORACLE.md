# Privacy and secret oracle

V1 policy is explicit: synthetic or real-looking credentials block the evidence bundle; they are not silently shipped or cosmetically redacted. Safe synthetic fixtures cover OpenAI-style keys, AWS secret assignments, private tokens, password assignments, and private-key headers across terminal, file/code, browser, desktop, and Resolve records.

Personal data may be redacted only when the CaptureSpec authorizes it and the derivative declares exact regions and reason. Raw retention then requires protected/quarantined storage and access policy; it does not license publishing the raw. Tests never read real environment variables, dotfiles, credentials, SSH material, `/proc`, or `/dev`.
