# Desktop application oracle

Generic desktop support is observation, not general computer use. An exact application id, executable, window title/id, machine session, monitor, expected ready state, focus identity, visibility, and occlusion ratio are required. Recent human input (under 15 seconds), focus changes, hidden/minimized/obscured windows, modal/not-ready state, wrong app/window/session, or unknown identity blocks capture.

Opening/closing applications, arbitrary clicks/typing, privilege changes, and unbounded interaction are outside Stage 7 V1.
