# CaptureSpec oracle

V1 requires: exact schema and capture id/time; claim, required facts, forbidden omissions; one typed source with full identity; static or bounded 0.25–10 s motion parameters; source-specific bounded action and completion time; known machine/session; explicit privacy policy with secret response `BLOCK`; approved output root and relative exact names; 1080×1920 presentation/safe-area/readability/context policy; and `FAIL_AND_REPLAN` with representation fallback false.

Unknown fields and unknown enum values are rejected, not silently normalized. Red coverage includes unknown source, missing target/identity/privacy, unsafe command, traversal/UNC/drive paths, output aliasing, unsupported mode, impossible duration/FPS, unknown machine, ambiguous app, malformed selector, hostile quoting, unsafe URL scheme, and arbitrary action.
