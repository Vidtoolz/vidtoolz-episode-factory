# ELIGIBILITY.md — permission declaration vs authorization eligibility (v1.3, FROZEN_NOW as law; evaluator is a reference, not runtime-qualified)

**Permission declaration** (`PERMISSIONS.json`, `allowed: true`): what an operation is theoretically permitted to do under a milestone and scope. **Authorization eligibility**: whether *this* request, the frozen authorities and the linked evidence set currently satisfy every prerequisite. `allowed: true` never makes a request eligible.

## v1.3 law: the evaluator consumes validated authority, never caller assertions

Reference evaluator: `authority_lib.evaluate_eligibility(perms, request, read_primitives, capabilities, target_contract, evidence_set)`.

Inputs are the frozen authorities (`PERMISSIONS.json`, `READ-PRIMITIVES.json`, `CAPABILITIES.json`, `TARGET-CONTRACT.json`) plus a **validated evidence set** (`schemas/resolveEvidenceSet.schema.json`: content-addressed records) and a **request** (`schemas/resolveEligibilityRequest.schema.json`): `milestone`, `operation`, `scope`, `expected_project_name?`, `expected_timeline_name?`, `transaction_id?`, `plan_digest?`, `plan_h0_guard_digest?`, `refs` (sha256 references by role: `authorization`, `journal_prepared`, `read_only_journal`, `guard`, `plan_validation`, `m0_exit`, `m1_exit`, `m2_exit`, `exclusive_session`, `media_class`, `destination_timeline`).

The request schema has `additionalProperties: false`: `attachment_state`, `capability_state`, `evidence`, `journal_available`, `guard_available`, `authorization_token` are **not request fields** (retired). The evaluator never reads them; the fixtures `m0-probe-deny-declared-state-ignored` and `m0-connect-deny-qualified-read-string-ignored` prove that a request carrying them is both schema-invalid and still denied.

Derived, not declared:
- **Attachment state** — `derive_attachment_state(target_contract, evidence_set)` (`TARGET-ATTACHMENT-GATE.md`). `TARGET_STATE_*` codes compare the derived state.
- **Primitive qualification** — `primitive_status(capabilities, primitive, method, evidence_set, env)`: `QUALIFIED_CALLABLE` only when the frozen row is `QUALIFIED_READ` **and** a `CAPABILITY_EVIDENCE` record for the same method with `host`, `resolve_version` and `build` equal to the target contract and a non-null `reviewed_refreeze_version` is linked; `PROBE_ALLOWED` only inside `READ_PRIMITIVE_QUALIFICATION_PROBE` for `probe_candidate` rows (`M0-PROBE-CONTRACT.md`); otherwise `UNQUALIFIED` and the declared fallback decides (`REFUSE` blocks).
- **Evidence references** — `resolve_ref(evidence_set, ref, expected_type, target, extra)`: a reference is evidence only if it is a lowercase 64-hex sha256, exists in the set, has the expected `record_type`, re-hashes to its id, belongs to the same target (`target.host_name`, `target.library_name` where present) and matches the required extra fields (e.g. `plan_digest`, `transaction_id`, `milestone`, `authority_version`, `scope`, `result`). `""`, `"false"`, uppercase, short, unlinked or wrong-type references fail (fixtures `m0-deny-ref-*`, validator section `evidence-ref-negative`).
- **Target requirement** — every permission entry and logical read operation declares `target_requirement ∈ {SESSION, PROJECT, PROJECT_TIMELINE}` (must agree; `semantic_read_primitives`). `SESSION`: host/library/session identity only (`READ_PRIMITIVE_QUALIFICATION_PROBE`, `CONNECT`, `ENUMERATE_PROJECTS`, `CreateProject`). `PROJECT`: `expected_project_name` required and proven by a `PROJECT_BINDING_OBSERVATION` for that name; the name must be adapter-prefixed or covered by an `OPERATOR_PROVISIONED_PROJECT` record (`ENUMERATE_TIMELINES`, `TRIPWIRE_READ`, `LoadProject_adapterPrefixed`, `CreateEmptyTimeline`, `SaveProject`, `ImportMedia`). `PROJECT_TIMELINE`: additionally `expected_timeline_name` proven by a `TIMELINE_BINDING_OBSERVATION` (`SNAPSHOT_CAPTURE`, `TIMEBASE_OBSERVE`, `SetCurrentTimeline`, `BUILD_MUTATION_PLAN_DRY_RUN`, every M3 timeline mutation). Mutation-capable entries additionally require `OBSERVED` project/timeline unique ids in the binding observations. **No operation ever binds to whatever project or timeline is current**; the binding observation is the only way a name becomes a target. The evaluator enforces the binding even if an entry omitted `TARGET_REQUIREMENT_SATISFIED` (schema requires it anyway).

Output: `permitted_by_policy`, `prerequisites_satisfied`, `eligible`, `failed_prerequisites[]` (code + reason), `reason_codes[]`, `derived_attachment_state`, `target_requirement`, `expanded_primitives[]` (method, status, callable, fallback). Unknown milestone/scope/operation/prerequisite, invalid evidence set, missing binding or unlinked reference fails closed.

## Prerequisite codes (closed set, `PERMISSIONS.json.prerequisite_codes`, 23)

`BUNDLE_INDEPENDENTLY_VERIFIED` (derived proof: `BUNDLE_VERIFICATION` for 1.3.0 with verifier ≠ preparer), `TARGET_STATE_ATTACHMENT_READY` / `TARGET_STATE_ATTACHED_READ_ONLY` / `TARGET_STATE_SCRATCH_WRITE_READY` (derived state rank), `HOST_MATCHES_CONTRACT` (valid provisioning record for contract host), `LIBRARY_NOT_SHARED`, `LIBRARY_MATCHES_CONTRACT` (no `OBSERVED_TARGET_MISMATCH`), `RESOLVE_VERSION_MATCHES` (connection observation proof), `M0_EXIT_EVIDENCE` / `M1_EXIT_EVIDENCE` / `M2_EXIT_EVIDENCE` (`MILESTONE_EXIT` record for that milestone and authority 1.3.0), `MIKKO_M3_AUTHORIZATION` (`M3_AUTHORIZATION`, scope `SCRATCH_QUALIFICATION_LIBRARY`, approver, authority 1.3.0), `JOURNAL_PREPARED` (`JOURNAL_PREPARED` for this `transaction_id` and `plan_digest`), `READ_ONLY_JOURNAL_OPEN`, `GUARD_CURRENT` (`GUARD_SNAPSHOT` whose `guard_digest` equals the plan's `h0_guard_digest` for the expected project/timeline), `EXCLUSIVE_SESSION_ATTESTED`, `PROJECT_ADAPTER_PREFIXED`, `PRIMITIVES_QUALIFIED_OR_DECLARED_UNOBSERVED`, `PROBE_ALLOWED_PRIMITIVES` (probe only), `PLAN_VALIDATED` (`PLAN_VALIDATION` PASS for this `plan_digest`), `SYNTHETIC_MEDIA_ONLY`, `TIMELINE_IS_DESTINATION` (`DESTINATION_TIMELINE` record for the expected names), `TARGET_REQUIREMENT_SATISFIED`.

## Consequences at v1.3

`CAPABILITIES.json` has zero `QUALIFIED_READ` rows, so `CONNECT` and `TIMEBASE_OBSERVE` (`REFUSE` fallbacks) are not eligible at any milestone until a reviewed refreeze; `READ_PRIMITIVE_QUALIFICATION_PROBE` is the first and only session-establishing M0 operation; `SNAPSHOT_CAPTURE`, `ENUMERATE_PROJECTS`, `ENUMERATE_TIMELINES`, `TRIPWIRE_READ` are eligible in degraded mode once the derived state is `ATTACHED_READ_ONLY` and their bindings are observed.
