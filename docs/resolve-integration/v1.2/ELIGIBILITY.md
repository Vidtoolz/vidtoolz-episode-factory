# ELIGIBILITY.md — permission declaration vs authorization eligibility (v1.2, FROZEN_NOW as law; evaluator is a reference, not runtime-qualified)

**Permission declaration** (`PERMISSIONS.json`, `allowed: true`): what an operation is theoretically permitted to do under a milestone and scope. **Authorization eligibility**: whether *this* request, target and evidence set currently satisfy every prerequisite. `allowed: true` never makes a request eligible.

Reference evaluator: `authority_lib.evaluate_eligibility(perms, request, read_primitives)`. Inputs: `milestone`, `operation`, `scope`, `target` {attachment_state, host_name, library_name, library_kind, observed_database_name, project_name, timeline_unique_id, resolve_version}, `evidence` {sha-referenced records}, `capability_state` {method → evidence_class}, `journal_available`, `guard_available`, `authorization_token`. Output: `permitted_by_policy`, `prerequisites_satisfied`, `eligible`, `failed_prerequisites[]`, `reason_codes[]`, `expanded_primitives[]`. Unknown milestone, scope, operation, prerequisite code or missing evidence fails closed.

Prerequisite codes (closed set, `PERMISSIONS.json.prerequisite_codes`): `BUNDLE_INDEPENDENTLY_VERIFIED`, `TARGET_STATE_ATTACHMENT_READY`, `TARGET_STATE_ATTACHED_READ_ONLY`, `TARGET_STATE_SCRATCH_WRITE_READY`, `HOST_MATCHES_CONTRACT`, `LIBRARY_NOT_SHARED`, `LIBRARY_MATCHES_CONTRACT`, `RESOLVE_VERSION_MATCHES`, `M0_EXIT_EVIDENCE`, `M1_EXIT_EVIDENCE`, `M2_EXIT_EVIDENCE`, `MIKKO_M3_AUTHORIZATION`, `JOURNAL_PREPARED`, `READ_ONLY_JOURNAL_OPEN`, `GUARD_CURRENT`, `EXCLUSIVE_SESSION_ATTESTED`, `PROJECT_ADAPTER_PREFIXED`, `PRIMITIVES_QUALIFIED_OR_DECLARED_UNOBSERVED`, `PLAN_VALIDATED`, `SYNTHETIC_MEDIA_ONLY`, `TIMELINE_IS_DESTINATION`.

Read expansion: `READ-PRIMITIVES.json` maps each logical read operation to primitives with evidence class and fallback. `PRIMITIVES_QUALIFIED_OR_DECLARED_UNOBSERVED` passes only if every primitive is `QUALIFIED_READ` in the request's `capability_state` or declares `MARK_UNAVAILABLE`/`DOWNGRADE_COVERAGE`; a `REFUSE` fallback blocks the operation (e.g. `CONNECT` before the probe qualified its getters). `READ_PRIMITIVE_QUALIFICATION_PROBE` is the only operation allowed to call `DOCUMENTED_NOT_QUALIFIED` getters, explicitly, to produce evidence records; it is therefore the first M0 operation.

Fixtures: `fixtures/eligibility/cases.json` (ALLOW: probe with attachment evidence; snapshot post-probe; snapshot pre-probe degraded; connect post-probe; M3 append with full evidence. DENY: unprovisioned target; EKA target; unknown library; production project name; wrong host; missing bundle verification; version mismatch; no journal; write op at M0; M3 without authorization; stale guard; shared-library scope; unknown milestone; unknown operation).
