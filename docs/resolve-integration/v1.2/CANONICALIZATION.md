# Canonicalization specification v1.2 (FROZEN_NOW; Node conformance = M1 work)

Reference: `tools/authority_lib.py`; vectors `fixtures/canonicalization/vectors.json`; rejections `fixtures/canonicalization/rejections.json`.

1. **Encoding/objects/strings/integers/booleans**: UTF-8, no whitespace, keys sorted by code point, exact strings with the fixed escape set, integers within ±(2^53−1). Bare floats, NaN, Infinity, lone surrogates rejected. No Unicode normalization: byte-distinct strings stay distinct (vector `unicode_byte_distinct_strings`).
2. **Tagged numerics (validated, not accepted as arbitrary strings)**: `{"$rational":"p/q"}` MUST match `^(0|[1-9][0-9]*)/([1-9][0-9]*)$` and be reduced (so `2/4`, `1/0`, `-1/2` are rejected). `{"$f64":"<16 lowercase hex>"}` is IEEE-754 binary64 big-endian; uppercase, short, non-hex, NaN/Infinity (exponent all ones) and negative zero (`8000000000000000`, must be `0000000000000000`) are rejected.
3. **Nullable fields** are emitted as `null`, never omitted.
4. **Typed array ordering** (applied by `normalize_snapshot_payload`): tracks by (type order video<audio<subtitle, integer index; string index and duplicate address rejected); items by (start, end, kind order, unique_id, `observation_ordinal`) with exact-tuple collision rejected; **markers by the total key (object_address, frame, duration, custom_data, name, color, note)**, and two markers sharing (object_address, frame) or exactly duplicated are rejected as `MARKER_COLLISION`; media dependencies by (locator, sha) with duplicates rejected. Ordering never relies on input order (vectors: reversed marker input gives the same digest; markers differing only in note or duration order deterministically).
5. **Duplicate JSON keys (policy A)**: canonicalization operates on parsed objects and cannot see source duplicates. Authority files MUST be loaded through `strict_loads`/`strict_load`, which reject duplicate keys at the parse boundary (`fixtures/parse/duplicate-key.json.txt`). The dictionary-level duplicate check in `canon` is a programming guard, not a source-duplicate detector.
6. **Domain-tagged digests**: `sha256(utf8(domain) + 0x0A + canonical_bytes)`; registered domains only (`vidtoolz.resolveSnapshotPayload.v1.2`, `vidtoolz.resolveGuard.v1`, `vidtoolz.resolveMutationPlan.v1`, `vidtoolz.resolveBindingSet.v1`, `vidtoolz.resolveJournalRecord.v1`, `vidtoolz.resolveGeneric.v1`).
7. `canonicalization_version` is `"1.2"`.
