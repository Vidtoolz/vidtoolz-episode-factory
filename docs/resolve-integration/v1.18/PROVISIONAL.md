# PROVISIONAL.md — what v1.6 deliberately does NOT freeze

Manifest field `status` is a closed vocabulary (`FROZEN_NOW`, `PROVISIONAL_UNTIL_M3`, `UNTESTED_BLOCKED`); `blocked_until` and `qualification_note` are separate structured fields. Nothing below is frozen fact.

**PROVISIONAL_UNTIL_M3 (drafts that give M3 exact questions; re-frozen only under the refreeze law in `M3-MATRIX.md`):**
- `schemas/provisional/`: `resolveSequenceLineage`, `resolveBindingSet`, `resolveBindingObservation`, `resolveMutationPlan` (v1.5: `session_id`), `resolveTransactionJournal` (v1.5: `session_id`, `readback_snapshot_sha256`, `readback_guard_digest` on `READBACK_S1`), `resolveVerificationResult` (v1.5: `session_id`; derived lists), `resolveConflict`, `resolveCommitManifest` (v1.5: `session_id`, `s1_snapshot_sha256`), `resolveCheckpoint`. The protected observation surface, the expected-effect law (`expected_effects`: APPEND/DELETE/DISABLE/ENABLE/UPSERT_MARKER), the `APPEND_VERIFY` profile and the composed validator `commit_eligibility_authorizing` / `validate_transaction_set_authorizing` / `verify_transaction` are references, not runtime-qualified; no runtime semantics beyond `expected_effects` are claimed for APPEND.
- `TIMEBASE.json.api_mapping` (recordFrame origin, endFrame convention, still duration, `GetStartFrame == 108000`).
- `TARGET-CONTRACT.json` fields `library.root_path`, `library.instance_uuid`, `session.launch_recipe_sha256`, `session.external_scripting_preference_observed` (required future observations; never fabricated).
- Track-policy **enforcement** by Resolve (`enforcement_evidence: NOT_TESTED`); the layout itself is frozen EF intent.
- `M3-MATRIX.md` and `M3-PROBES.json` (plan, not evidence); semantic validators, the eligibility evaluator, the reference capture shim and the reference parser (reference only, not runtime-qualified); the evidence-set record types and envelope (`schemas/resolveEvidenceSet.schema.json`) are a contract for records that do not yet exist — real M0A captures must reconcile against it; the derived attachment state is UNPROVISIONED until a provisioning record exists; occurrence-identity uniqueness is fail-closed offline — if Resolve can produce duplicate ids a composite identity must be frozen before verification relies on it; `MAX_OBSERVATION_AGE_S = 3600` is a frozen rule whose value M0 may show needs adjusting through a versioned correction.
- **Every primitive expectation** (`receiver`, `arg_types`, `nullable`, `expected_type`, `shape_rule`, `completeness`) is `DOCUMENTED_HYPOTHESIS` (`PRIMITIVE-SPEC.md`): it comes from the 21.1 README and stub, not from an observation on this host, and `primitive_spec_law.frozen_allowed` is `false`. A classification against a hypothesis is not a qualification. Correcting an expectation changes `primitive_spec_sha256` and invalidates promotions bound to the old one.
- The derived-class vocabulary and the check order of `REFERENCE-PARSER.md`, the parser identity mechanism, and whether `stdout`/`stderr` digests are forensically required (`M0A-PROBE-COMPATIBILITY.md` §4) await independent review.
- The **exclusions** of `PROTECTED_SURFACE_EXCLUSIONS` (item properties, fades, speed, takes, links, unowned media hashes) are an honest narrowing, not a claim that they are safe: representing and comparing them is future work behind its own probe and refreeze.
- The H0/S0 early write gate, the mandatory checkpoint and the derived applied-operation comparison are reference rules for a transaction path that remains PROVISIONAL_UNTIL_M3.

**UNTESTED_BLOCKED (every `CAPABILITIES.json` row with `evidence_class` NOT_TESTED or DOCUMENTED_NOT_QUALIFIED blocks each dependent milestone):** in v1.6 **every read row** is DOCUMENTED_NOT_QUALIFIED and `probe_candidate: true` (probe-callable only; PROBE_ALLOWED != QUALIFIED_READ; `refreeze.reviewed: false`, empty promotion lists) because no raw capture exists on Resolve 21.1.0 build 14 (prior-version records are attached with `version_match: false`, `result: UNQUALIFIED_PRIOR_VERSION` and no probe id); all mutation rows; `-nogui` mutation; scratch lifecycle; `GetUniqueId` **survival** (separate from callability, uniqueness and stability — `IDENTITY-EVIDENCE.md`).

**BLOCKED in v1 regardless of tests:** `ReplaceClip`/`RelinkClips`; ripple delete; `SetCurrentDatabase`; `CloseProject`; `ImportProject`; render/delivery before M11; any MCP script tool; `EKA`; publishing.
