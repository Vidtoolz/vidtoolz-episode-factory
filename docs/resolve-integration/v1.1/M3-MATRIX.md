Scratch lifecycle (`CreateProject`, `CreateEmptyTimeline`, `SaveProject`, reopen the same adapter-prefixed project) is permitted only inside the qualification library.

**Overclaim rules (apply to every row):** one probe qualifies exactly the primitive, argument shape and object class it exercised. One lock test does not qualify all mutators. One `-nogui` pass qualifies only the probes run under `-nogui`, never M4–M8. One `GetUniqueId` survival result qualifies only the operations tested. One `GetProjectLastModifiedTime` change is not CAS. One collision outcome is not a general collision law. One save/reopen is not full recovery qualification.

## Refreeze law
A capability row moves `NOT_TESTED`/`DOCUMENTED_NOT_QUALIFIED` → `QUALIFIED_*`, or a provisional schema → `FROZEN`, only when **all** hold: (a) a `probe-<n>.json` with S0/S1 guard digests and journal exists for that exact primitive/argument shape; (b) expected and actual observations match, or the schema is amended to actual behaviour and re-versioned; (c) failure behaviour (False/nil/timeout/partial) is characterized; (d) concurrency implications are recorded; (e) a readback/verification path detects its effect; (f) recovery semantics for a crash inside it are fault-tested. The refreeze is bundle **v2.0.0** with its own manifest and approval. No freeze by documentation, by another primitive's result, or by an estate script that used deprecated forms.
