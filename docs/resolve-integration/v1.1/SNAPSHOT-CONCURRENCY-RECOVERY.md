# Snapshot, concurrency and recovery doctrine v1.1 (FROZEN_NOW as doctrine; schemas PROVISIONAL_UNTIL_M3)

v1.1 changes: (1) the pre-write version token is the composite **guard digest** (`GUARD-AUTHORITY.md`), not the payload digest; (2) snapshot items carry provenance variants so real human timelines (titles, generators, compound and adjustment clips, Fusion, offline media) are representable (`schemas/resolveSnapshot.schema.json`); (3) `STALE_ASSET` is judged against the Episode Factory canonical head and `IMPORT_OVERRIDE` is replaced by `PROPOSE_REVIEW_NOTE` (`DRIFT-POLICY.md`); (4) coverage carries `deferred_domains` alongside `unobservable_domains`.

**Doctrine:** `BEST_EFFORT_OPTIMISTIC_CONCURRENCY` + `EXCLUSIVE_SESSION_REQUIRED_FOR_WRITES`.

**Resolve provides (verified 2026-09-08):** no revision counter, CAS, change events, undo or timeline-lock API; `AppendToTimeline` acts on the *current* timeline; `SetTrackLock/GetIsTrackLocked` exist (effect on API writes NOT_TESTED); `GetProjectLastModifiedTime` exists (advisory); project-server collaboration locks at project granularity (observed in `ResolveDebug.txt` 2026-09-08); `SetSettings` may keep earlier settings and return False (README.md:243).

**Guaranteed:** (1) any in-coverage change between H0 and the pre-apply stable reread → `SNAPSHOT_CONFLICT`, zero mutators; (2) any in-coverage change between declared phases blocks remaining calls; (3) full S1 comparator detects `UNEXPECTED_DELTA` and `EXPECTED_DELTA_MISSING`, no commit; (4) never write outside destination/owned objects or a frozen plan; never after detected conflict; never delete/move human changes in recovery; (5) `LEASE_BUSY` between VIDTOOLZ workers; (6) every outcome incl. False/nil/timeout → readback → terminal state.

**Not guaranteed (must accompany every success report):** prevention of GUI/other-client edits between last read and a mutator call (residual race; concurrent human edit during a transaction = CONFLICT detected at earliest readback, not prevented); detection outside coverage (`UNOBSERVABLE_STATE`: grades, Fusion graphs, caches, nested timelines, keyframe curves); atomicity of composed operations or of mutation+save+publication; rollback; ABA.

**Snapshot:** envelope (schema/collector/canonicalization versions, target epoch, product/build, library/project identity, coverage mask with `complete`/`observed`/`unobservable`/`deferred`, policy pins, `payload_sha256`, `guard_digest`, `hash_domains`; collection timestamps and `last_modified_time_observed` outside both digests) + hashed payload: project/library context; timeline (id, name, start frame/TC, rational fps, dimensions, settings); every track (type, index, name, enable/lock, all items incl. unowned); every item (type, unique id, name, track address, start/end/duration subframe, source range, enabled, pool identity, source identities/availability, speed, transforms/audio props, fades, links, takes, markers, effect coverage); every marker (frame, duration, color, name, note, customData); media dependencies (logical locator, sha256/size, conform policy). `UNOBSERVABLE_STATE` domains explicit. Excluded: collection times, transport latency, playhead/selection/page, cache progress, object reprs, host diagnostic paths. Stable collection = two consecutive equal **guard digests** within ≤3 pairs. Items: MEDIA_BACKED (pool id + source status HASHED/UNHASHED_UNOWNED/OFFLINE) or GENERATOR/TITLE/COMPOUND/ADJUSTMENT/FUSION_OR_GENERATED/OTHER_OBSERVED (null source, `absence_reason`); nullable fields emitted as null.

**Transaction state machine:** `PREPARED` (journal fsync before any mutator) → `LEASED` → `PREFLIGHT_OK` (stable reread guard digest == H0 guard digest) → `CHECKPOINTED` (DuplicateTimeline + DRT export + SaveProject, themselves journaled) → `APPLIED_n` with intermediate readback per phase → `READBACK_S1` → `VERIFIED` (`unrelated=[]`, `missing_expected=[]`) → `SAVED` (saved-state verification) → `PUBLISHED` (EF compare-and-swap on source pins; changed pins → `AUTHORITY_CHANGED`) → `COMMITTED`. Terminal: `COMMITTED`, `COMMITTED_RECOVERED`, `NOT_APPLIED`, `CONFLICT`, `ORPHANED_PARTIAL`, `ORPHANED_AMBIGUOUS`.

**Recovery:** reconcile observations, never replay. S0 exact → `NOT_APPLIED`; exact intended S1 + persistence + EF pins unchanged → `COMMITTED_RECOVERED` (publish once); else orphan, preserve destination/journal/checkpoint, block further mutation. Never re-append because a marker is missing; never clean up orphaned objects automatically.

**Drift policy:** see `DRIFT-POLICY.md` (`PRESERVE | PROPOSE_REVIEW_NOTE | REQUEST_RECONCILIATION | STOP`; `STALE_ASSET` vs EF head; Resolve observation never becomes EF truth).

**Conflict codes:** TARGET_MISMATCH, LIBRARY_NOT_QUALIFIED, SESSION_NOT_EXCLUSIVE, LEASE_BUSY, CAPABILITY_MISMATCH, SNAPSHOT_UNSTABLE, SNAPSHOT_INCOMPLETE, SNAPSHOT_CONFLICT, AUTHORITY_CHANGED, TIMEBASE_MISMATCH, TIMEBASE_UNRESOLVED, TIMEBASE_COLLAPSED_INTERVAL, IDENTITY_AMBIGUOUS, IDENTITY_EPOCH_CHANGED, UNOWNED_CONTENT, MARKER_COLLISION, MEDIA_CHANGED, MEDIA_UNAVAILABLE, UNOBSERVABLE_STATE, EXPECTED_DELTA_MISSING, UNEXPECTED_DELTA, SAVE_UNVERIFIED, MUTATION_OUTCOME_UNKNOWN, RECOVERY_REQUIRED, JOURNAL_CORRUPT. Drift classes: NO_DRIFT, EXPECTED_HUMAN_OVERRIDE, STALE_ASSET, MISSING_ASSET, POSITION_DRIFT, DURATION_DRIFT, UNKNOWN_TIMELINE_ITEM, POLICY_VIOLATION. A conflict or drift is never permission to repair.
